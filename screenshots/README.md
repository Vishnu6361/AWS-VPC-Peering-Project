# Project Evidence Screenshots

This directory stores verification screenshots captured during deployment and connectivity testing in your AWS account.

## Directory Structure
- `checkpoints/`: Contains the 18 milestone verification screenshots required by the evaluation grading rubric and embedded into the automated PDF report generator (`report_generator/generate_report.py`).
- Place raw terminal or console captures in this root folder if desired.

See `checkpoints/README.md` for the exact naming conventions and capture specifications.
